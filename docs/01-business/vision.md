# Vizyon

## Bir cümlə ilə
Şirkət daxilində developer və QA bir düymə ilə brauzerdə gedən bütün API trafikini yazıb fayl kimi yükləsin və bir-birinə göndərsin, QA isə eyni əməliyyatın müxtəlif cəhdlərini müqayisə edə bilsin — Inspect açmadan.

## Məqsədlər
1. QA ilə developer arasında "Inspect aç, Network-a bax, payload-u kopyala" yazışmalarını aradan qaldırmaq.
2. Bug-ların səbəbini (payload, response, status, xəta) ilk mesajda əldə etmək.
3. QA üçün response müqayisəsi ilə backend dəyişikliklərini / reqressiyaları tez tutmaq.
4. Datanın üçüncü tərəf serverlərə getməməsi (Jam və s. əvəzinə daxili alət).

> Müştəri dəstəyi (müştərinin özünün qeyd etməsi) hələlik hədəf deyil — bax: [users.md](users.md).
