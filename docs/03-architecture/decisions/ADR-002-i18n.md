# ADR-002 — Çoxdilli interfeys üçün i18n

**Status:** 🟢 Qəbul edildi · **Tarix:** 2026-11-03 · **Mənbə:** Sessiya #1, Q5

## Kontekst
İnterfeys dili hələlik Azərbaycan dilidir, amma gələcəkdə başqa dillər (EN, RU və s.) əlavə oluna bilər. Mətnləri koda birbaşa yazsaq, sonradan dil əlavə etmək bütün UI-ı yenidən yazmaq deməkdir.

## Variantlar
1. **`chrome.i18n` (Chrome-un daxili sistemi)** — `_locales/<dil>/messages.json`, əlavə kitabxana yoxdur, `manifest.json`-da da işləyir (ad, təsvir). Dil brauzerin dilinə görə avtomatik seçilir; extension daxilində dəyişmək olmur.
2. **Öz kiçik i18n modulumuz** — eyni `messages.json` formatı, amma dil ayarlardan seçilir və `chrome.storage`-da saxlanılır.
3. **Kənar kitabxana (i18next və s.)** — güclü, amma bu ölçüdə layihə üçün artıqdır.

## Qərar
**Variant 1 + 2 birlikdə:**
- Bütün tərcümələr `chrome.i18n` formatında: `_locales/az/messages.json`, `default_locale: "az"`.
- UI kodu mətnləri yalnız bir köməkçi funksiya ilə götürür: `t("key")`. Kodda heç bir hardcoded mətn olmur.
- MVP-də `t()` sadəcə `chrome.i18n.getMessage()`-i çağırır.
- İkinci dil əlavə olunanda `t()` dəyişdirilib ayarlardan dil seçimi əlavə olunur — UI koduna toxunmadan.

## Qaydalar
- Yeni mətn → əvvəlcə `_locales/az/messages.json`-a key, sonra kodda `t("key")`.
- Key adları: `snake_case`, bölmə prefiksi ilə (`popup_start`, `popup_stop`, `har_download`, `compare_title`).
- Texniki terminlər (request, response, header, payload, status) tərcümə olunmur.
- Tarix/rəqəm formatı: `Intl.DateTimeFormat` / `Intl.NumberFormat` cari dil ilə.

## Nəticələr
- Yeni dil = yeni `messages.json` faylı (+ ayarlarda seçim).
- Başlanğıcda kiçik əlavə iş: hər mətn üçün key.
- Code review-da hardcoded mətn yoxlanılır (PR şablonuna checklist bəndi).
