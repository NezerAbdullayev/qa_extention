## Qərarlar
- **Q1:** Siyahı **side panel**-də göstərilir. Panel: ✕ düyməsi ilə bağlanır (qeyd dayanmır); — / ▢ düyməsi ilə kompakt ↔ tam rejim; eni sol kənardan əl ilə dartılaraq dəyişir, seçim yadda qalır. Məhdudiyyət: en Chrome tərəfindən idarə olunur (min ~320px), kompakt rejim yalnız məzmunu yığır. → `F-008`, `overview.md` yeniləndi.
- **Q6:** Müqayisə **yalnız response body**-ni yoxlayır. Payload, headers, status kodu, müddət müqayisə olunmur. → `F-004`, `requirements.md` (FR-08) yeniləndi.
- **Q3:** Bağlı sətirdə API adı brauzerin DevTools → Network "Name" sütunu ilə **eyni** göstərilir: URL-in son path seqmenti + query string (məs. `MY_TASKS_COLUMNS`, `passports`, `tasks?sort=regNumber&taskStatus=IN_WORK`, `find.batch`, `list?checkFin=true`). Hover → tam URL. **Əlavə:** addan sonra method, status, müddət göstərilir (xətalar qırmızı). Hər açılan qutu **sabit 500px** hündürlükdə, daxildə scroll. → `F-008`, `requirements.md` (FR-13) yeniləndi.
- **Q5:** Açıq qutuda məzmun **JSON formasında**, alt-alta bu sıra ilə: 1) API-nin tam ünvanı, 2) altında `method: GET`, 3) Headers (JSON obyekt), 4) Response (formatlanmış JSON). → `F-008`, `requirements.md` (FR-14) yeniləndi.
- **Q11:** Yalnız **XHR / Fetch** request-ləri yazılır və siyahıda göstərilir. Şəkil, CSS, JS, font, HTML sənəd yazılmır. (Sessiya #1, Q6-nın cavabı.) → `F-001`, `F-008`, `requirements.md` (FR-02) yeniləndi.
- **Q14:** Response body JSON deyilsə (HTML, mətn, boş, parse olunmayan JSON) → həmin API **müqayisə olunmur**, hesabatda xəbərdarlıq göstərilir: "⚠️ Response JSON formatında deyil — müqayisə mümkün deyil". → `F-004` yeniləndi.
- **Q5a (Q5-ə düzəliş):** Açıq qutuda **Payload** da göstərilir. Yekun sıra: 1) tam URL, 2) `method: …`, 3) Headers, 4) **Payload** — göndərilən hissə (body + query parametrləri, DevTools "Payload" tab-ı kimi), 5) Response — qayıdan hissə. Payload yoxdursa bölmə gizlənir. → `F-008`, `requirements.md` (FR-14) yeniləndi.
- **Q5b:** Açıq qutuda **hər iki** header növü ayrı başlıqlarla göstərilir: **Request headers** (göndərilən) və **Response headers** (qayıdan). Yekun sıra: URL → method → Request headers → Response headers → Payload → Response. → `F-008`, `requirements.md` (FR-14) yeniləndi.
- **Q15 (Q3-ə düzəliş):** Açılan qutunun hündürlüyü **sabit deyil**: məzmuna görə dəyişir, **maksimum 500px**. Qısa response-da qutu kiçik olur; 500px-dən çox olanda qutunun daxilində scroll. → `F-008`, `requirements.md` (FR-13) yeniləndi.
- **Q12:** Yeni Start basılanda əvvəlki qeydin siyahısı silinir. Əvvəlki qeyddən 💾 ilə yadda saxlanmış API-lər **qalır**, qalanları silinir. → `F-008` yeniləndi.
- **Q13:** Siyahıda axtarış və filtr **lazım deyil**. → `F-008` yeniləndi.
- **Q5c:** Açıq qutuda `method: GET`-in altında **`status: 200`** də yazılır (müddət açıq qutuda yox, yalnız bağlı sətirdə). → `F-008`, `requirements.md` (FR-14) yeniləndi.
- **Q2:** Siyahı **canlı** yenilənir: hər request baş verən kimi dərhal siyahıya əlavə olunur (DevTools → Network kimi). Stop basmadan da sətiri açmaq və 💾 ilə saxlamaq olur. → `F-008`, `F-001`, `requirements.md` (FR-13) yeniləndi.
