## Qərarlar
- **Q0:** Saxlanmış API-lər **IndexedDB**-də, `savedApis` store-unda saxlanılır. Cari qeyd (`requests`) Start-da silinir, `savedApis` heç vaxt avtomatik silinmir. Brauzer / kompüter yenidən başlasa da, extension ⟳ olunsa da qalır; extension silinəndə silinir. Başqa kompüter / profil görmür — paylaşmaq JSON export / import ilə.
- **Q1:** Panelin yuxarısında iki tab: **Qeyd** (cari request-lər) və **Saxlanmışlar**.
- **Q2:** Ad unikal olmalıdır; təkrar ad → popup-da xəbərdarlıq, saxlanmır. Avtomatik 6 rəqəmli ad da unikal generasiya olunur.
- **Q3:** Avtomatik silmə yoxdur.
- **Q4:** Extension daxilində (siyahı, detallar, müqayisə) **real dəyərlər** görünür. **Export faylında** (JSON, gələcəkdə HAR) həssas sahələr `***` ilə mask olunur. Bu, Sessiya #1 Q7-nin də cavabıdır.
- **Q5:** JSON export (seçilmiş və ya hamısı) və import MVP-dədir.
- **Q6:** Qruplaşdırma yoxdur.
- **Q7:** Saxlama popup-unda yalnız **ad** sahəsi.
- **Q8:** `manifest.json`-a sabit `key` əlavə olunur → extension ID-si "Load unpacked" qovluğunun yerindən asılı olmur.
